# 营业统计与账单复核规则

营业额和实收口径：只统计已结、已人工复核、没有重复争议的账单。金额以整数分计算，再转换为元展示；不依据大模型生成金额。

日期规则：business_date 是上传时选择的归档日期，bill_date 是票面识别日期。趋势、房间排行和 Agent 查询默认按归档日期；账单列表日期筛选按票面日期。

重复规则：同日同文件 SHA-256 返回原图片；不同照片同账单编号首先标为疑似重复，暂停入账。人工保留原始账单后其他照片仅保留追溯，撤销确认重新暂停统计。

复核规则：关键字段缺失、置信度低、实收与应收不一致、负数金额、时间错误或时长差异均需要人工检查。原始 OCR 文本和人工修改历史保留；重识别不覆盖人工值或确认空值。

安全规则：业务分析只有只读查询工具，不执行用户输入的任意 SQL，不删除或修改账单，不访问原图、会员卡号和联系方式。需要改账时进入账单详情人工操作。

样本说明：统计仅反映已采集、符合口径的样本，不能推断为全部营业数据。没有符合条件的数据时返回零或空列表，不猜测补齐。
