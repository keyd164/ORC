日期：2026-10-26。依据：用户提供全栈与 Agent 路线，明确选择“升级当前项目，继续开发全栈与 Agent 功能”。原始材料归档在 references/fullstack-agent-roadmap-2026-10-26.md。

本修订优先于 V1.1；未修改部分继续沿用 V1.1 与 V1.0。小程序仍是最终日常操作端，首页保持采集、管理双入口；Vue 管理端可选，共用同一后端和数据库。

## 现状校正

外部材料根据小程序 ZIP 推断“后端、OCR、数据库尚未实现”，仅反映 ZIP 不包含这些内容，不代表完整仓库现状。已有 FastAPI、SQLite、本地 PaddleOCR、复核、导出、备份及验证不重建，不降级为前端原型。

## 当前升级交付（0.3.0）

1. 可选网页迁移 Vue 3 + TypeScript，启用严格类型检查和类型化接口封装，保留原有图表与业务界面。
2. 小程序数据管理、网页侧栏增加“本地业务分析”，支持提问、历史、执行日志、数据来源跳转和 Markdown 报告下载。
3. LangGraph 编排“规划 → 受限工具 → 证据回答”，LangChain StructuredTool 校验工具输入；SQLAlchemy 作为新增查询工具的数据访问层，原有事务与 OCR 不整体重写。
4. 工具支持有效实收汇总、房间排行、账单明细、异常/待复核/OCR失败记录和业务规则检索；金额异常单独筛选。日期按归档日期，明确解析今天、昨天、本周、本月等及显式日期范围。
5. 默认规则模式：无需模型即可运行固定查询，必须明确标识为规则路由，不宣称大模型推理。可选本机 Ollama 结构化规划模式，只允许本机且已下载的本地模型；无配置或失败时返回错误，不悄悄伪装成模型成功。
6. 金额、数量、排序由数据库确定，证据回答由模板生成，模型不负责生成金额；文档采用受限本地关键词检索，不宣称已完成向量 RAG。
7. 新增 agent_runs/agent_steps，保存工具参数、结果、耗时、错误及节点状态。启动将未完成任务标为 interrupted；用户可从已保存进度重试纯查询，不重复已完成工具。
8. 业务工具数据库连接强制 query_only；无任意 SQL、删除、改账、原图读取或外部服务工具。分析记录和日志仍写入本地数据库，业务账单数据只读。修改账单继续在详情人工操作，不新增自动改账能力。
9. 禁用 LangSmith 托管追踪；问题、工具结果和业务数据只保存在本机。报告由用户主动下载，不自动发送。
10. 配套自动测试、固定日期路由评测、依赖锁定、环境模板、Docker/Compose 与 GitHub Actions 配置。配置文件存在与真正运行/上线分别记录。

## 完整学习路线的后续阶段

- 实际本地模型联调及独立业务任务集成功率、向量检索效果比较。
- 如确需 Agent 写操作，另行设计受控审批状态和确认接口，不能复用聊天文本作为授权。
- 整体数据层 ORM/迁移、认证权限、更多并发和数据规模验证，按业务需要推进。
- Docker 构建运行、CI 远端执行、真实票据精度、微信真机、演示素材、实际 GitHub 发布与简历量化材料。

上述未完成项不得作为当前成果。不开通云端/付费 OCR 或模型服务，不把新增框架当作真实能力证明。
