# KTV 账单小程序 · 0.3.0

在微信开发者工具中导入本目录（包含 app.json 的目录）。项目无运行时 npm 依赖，不需要构建 npm。

首页提供“账单采集”和“数据管理”两个入口。需要电脑运行配套 Python 后端，小程序不依赖网页工作台。

1. 在完整项目中运行 scripts/run_backend.bat。
2. 微信开发者工具导入本目录。目前 AppID 为 touristappid，实际预览和真机使用你的小程序 AppID 和开发者账号。
3. 小程序“设置”输入后端地址并测试连接。电脑模拟器可用 http://127.0.0.1:8000；手机填电脑实际局域网地址，例如 http://192.168.1.10:8000（仅示例）。
4. 按实际账号配置相机/相册功能的隐私声明与权限，以及开发调试网络设置。当前 urlCheck:false 仅用于开发，不表示已经满足正式发布要求。
5. 从首页采集，上传记录可查看进度；数据管理可筛选、核对、复核、处理重复、看统计；设置可导出与备份。

图片与数据库保存在电脑。金额表单单位为元，统计仅含已结、已复核且无重复争议账单。原图与 OCR 历史保留，人工修正不被重识别覆盖。

Excel 可预览；CSV/ZIP 下载后使用文件菜单手动保存。整库恢复需要先关闭电脑后端，按完整项目 scripts/restore.py 说明离线执行。

本版本已通过 10 页模板/样式编译及模拟微信 API 流程测试，尚未完成实际 AppID 下的开发者工具和微信真机验收。真实票据精度需标注图片集验证。

0.3.0 新增：数据管理 → 本地业务分析。默认规则查询调用真实业务工具；Ollama 模式需电脑另行配置本地模型。可查看来源和步骤、重试失败任务、下载报告。规则模式不是大模型推理，关键词文档检索不是向量 RAG。
